# こよみちゃん (Koyomi chan)

自分好みに整えられる日本語カレンダーアプリです。土日祝・六曜・和暦の表示、
予定の色分け・繰り返し・複数リマインダー、ホーム画面ウィジェットに対応し、
Googleカレンダーとの同期・Googleドライブへのバックアップ(いずれも任意)が使えます。

Koyomi chan is a personal calendar app for Android. It supports Japanese
holidays and traditional calendar info, color-coded events, repeat rules,
multiple reminders, and home-screen widgets. Optional Google integration
provides two-way sync with Google Calendar and private backup to Google Drive.

- 対応プラットフォーム / Platform: Android (Google Play)
- パッケージ名 / Package: `io.github.xwingcat.koyomi`
